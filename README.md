# YtdlpJava

Универсальный менеджер загрузок с YouTube на базе Java и `yt-dlp`. Позволяет скачивать субтитры, аудио, видео и делать раскадровку (скриншоты).

## Возможности
- 📝 **Субтитры**: Скачивание и очистка от таймкодов и служебных тегов.
- 🎵 **Аудио**: Извлечение звука в форматах OPUS, MP3, M4A с настройкой качества.
- 📸 **Скриншоты**: Автоматическая раскадровка видео через заданные интервалы (использует `ffmpeg`).
- 📺 **Видео**: Простое скачивание видеофайлов (до 720p).
- 📜 **Плейлисты**: Автоматическая обработка всех видео в плейлисте или на канале.
- 📅 **Умные имена**: Автоматическое извлечение даты из названия и очистка имен файлов.

## Требования
1. **Java 21** или выше.
2. **yt-dlp**: Должен быть доступен в PATH.
3. **ffmpeg**: Необходим для извлечения скриншотов и конвертации аудио.

## Использование

### Сборка
```bash
mvn clean package
```

### Запуск
```bash
java -jar target/ytdlp-java-1.0-SNAPSHOT.jar "URL" [аргументы]
```

### Основные аргументы
| Флаг | Описание | По умолчанию |
|------|----------|--------------|
| `-t`, `--type` | Тип задачи: `sub`, `audio`, `screenshot`, `video` | `sub` |
| `-o`, `--output_dir` | Папка для сохранения результата | `output` |
| `-l`, `--lang` | Язык субтитров | `en` |
| `-i`, `--interval` | Интервал между скриншотами (сек) | `60` |
| `--format` | Формат аудио (`opus`, `mp3`, `m4a`) | `opus` |
| `--quality` | Качество аудио (`0` - лучшее, `9` - худшее) | `0` |

---

## Примеры команд

### 1. Скачивание и очистка субтитров
```bash
java -jar ytdlp-java.jar "https://youtu.be/..." -t sub -l ru
```

### 2. Извлечение аудио (MP3, высокое качество)
```bash
java -jar ytdlp-java.jar "https://youtu.be/..." -t audio --format mp3 --quality 0
```

### 3. Создание скриншотов каждые 30 секунд
```bash
java -jar ytdlp-java.jar "https://youtu.be/..." -t screenshot -i 30
```

### 4. Скачивание всех видео из плейлиста
```bash
java -jar ytdlp-java.jar "https://www.youtube.com/playlist?list=..." -t video
```

## Логирование
Проект использует SLF4J и Logback. Уровень логирования можно настроить через файл `src/main/resources/logback.xml` (если он создан) или системные свойства.
