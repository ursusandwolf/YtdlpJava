# YtdlpJava 1.0.0

**Первый публичный выпуск · Java 21 · Windows и Linux · MIT**

Одна YouTube-ссылка — и готовые материалы: текст, аудио, видео, кадры или метаданные.
Релиз объединяет пять CLI-задач, обработку плейлистов и исполняемый JAR
со всеми Java-зависимостями.

## Скачать и запустить

| Файл в Assets | Назначение |
|---|---|
| `ytdlp-java-1.0.0.jar` | Готовое приложение с зависимостями и словарями |
| `SHA256SUMS` | SHA-256 для проверки целостности JAR |
| Source code | Исходники тега `v1.0.0`, автоматически предоставляемые GitHub |

Нужны **Java 21+**, **yt-dlp**, **FFmpeg** и **Node.js** в PATH.
Maven нужен только при сборке из исходников.

```shell
java -jar ytdlp-java-1.0.0.jar --help
java -jar ytdlp-java-1.0.0.jar "https://youtu.be/VIDEO_ID" -t sub -l de
```

Проверка файла: `Get-FileHash ytdlp-java-1.0.0.jar -Algorithm SHA256` в PowerShell;
`sha256sum -c SHA256SUMS` в Linux. Сравните результат с опубликованной суммой.

## Возможности

| Задача | Что сохраняется |
|---|---|
| `sub` | VTT → Markdown: текст, таймкоды, выделение и список ключевых слов |
| `audio` | OPUS, MP3 или M4A |
| `video` | Видео с предпочтением MP4 до 720p |
| `screenshot` | JPEG через указанный интервал |
| `metadata` | JSON с данными видео |

Поддерживается анализ текста на EN, RU, UK, DE, ES, FR и IT. Без аргументов
открывается интерактивный мастер. Несколько URL и плейлисты обрабатываются последовательно;
ошибка одного элемента не мешает остальным. Совпадающие имена получают суффиксы.

## Надёжность выпуска

- Каждая загрузка изолирована во временном каталоге; существующие файлы сохраняются.
- Кириллица и диакритика проходят границу Java/yt-dlp в UTF-8.
- Прерывание завершает доступные дочерние процессы и очищает временные файлы.
- Есть таймауты, повторы временных ошибок и проверка ответов Telegram API.
- Поддерживаются VTT с LF, CRLF и CR, авторские и автоматические субтитры.
- Неверные аргументы возвращают код `2`, ошибки обработки — `1`, успех — `0`.

## Проверки

**120 модульных проверок + 3 проверки готового JAR.** CI выполняет полный
`mvn clean verify` на Java 21 под Windows и Linux. Отдельно проверяются старт из
постороннего каталога, коды завершения и наличие словарей семи языков.

Реальные проверки на Windows:

- Пять задач на Shorts `N3vr7ir5BXc`; видео и аудио полностью декодируются FFmpeg.
- Публичный плейлист **GRAMMATIK EXPRESS**: шесть файлов метаданных и шесть
  немецких Markdown-текстов; результаты сгруппированы по названию плейлиста.
- Недоступное видео, продолжение следующего URL и повторная загрузка без перезаписи.
- Прерывание потока и отдельная проверка Ctrl+C в Windows-консоли.

## Изменения для пользователей прежнего SNAPSHOT

Вместо настройки classpath используйте `java -jar ytdlp-java-1.0.0.jar`.
Параметры CLI сохранены. Инструменты `yt-dlp`, FFmpeg и Node.js по-прежнему
устанавливаются отдельно. Добавлена лицензия MIT; зависимости сохраняют свои лицензии.

## Известные ограничения

- Поддерживается VTT; JSON3/SRV не конвертируются.
- Последний резервный видеоселектор `best` может превышать 720p.
- Доступность видео и субтитров зависит от YouTube и версии yt-dlp.
- Точность автоматических субтитров определяется исходной дорожкой.
- Telegram подключается в коде; отдельной настройки через CLI пока нет,
  реальная отправка в этом выпуске не проверялась.
- Реальные медиа-проверки выполнены на Windows; Linux проверен автоматической сборкой
  и тестами, включая запуск готового JAR.
