## Текущее состояние

YtdlpJava — единый Maven-проект на Java 21 с пятью задачами CLI:
субтитры, аудио, видео, скриншоты и метаданные. Субтитры обрабатываются в Markdown
с анализом ключевых слов для EN/RU/UK/DE/ES/FR/IT.

Основная ветка для получения исходников — `main`. Maven-версия: `1.0-SNAPSHOT`.
Исторические версии 1.x в changelog не обозначают опубликованные Git-теги.
На момент слияния тег и релиз не создавались; файла лицензии нет.
